Core Differentiators

Built for enterprises that cannot afford document leaks.

Zero Document Retention

Data Privacy

We do not store your files. SearchPoint indexes metadata, keywords, and text summaries in OpenSearch. Raw binaries are parsed in isolated, ephemeral sandboxes and immediately purged.

Query-Time Purview & RBAC

Access Control

The #1 enterprise fear with AI search (oversharing) is architecturally prevented. Every query filters results per user. If someone can't open a file in OneDrive, they cannot see or query it.

Sub-50ms Desktop Speed

Search Performance

Press Ctrl + Space from any active application. Features boolean operators (AND/OR/NOT), fuzzy matching, multilingual stemming (English + Indonesian), and field boosting.

Intelligent On-Device Rename

On-Device AI

Eliminate chaotic downloads like `download(3).pdf`. A lightweight on-device neural model reads document structure and proposes standardized, clutter-free naming conventions.

Grounded AI Context (RAG)

AI Grounding

Feed ChatGPT, Claude, or local Ollama with verified corporate citations. LLMs receive only permitted departmental snippets, preventing hallucinations and executive data leaks.

Self-Hosted Private Stack

Deployment

Deploy entirely within your enterprise tenant or private VPC. Secrets rotated in HashiCorp Vault with KMS auto-unseal. Client certificates verified at proxy edge with CRL checking.

Architectural Blueprint

Inside the Knowledge Layer.

How SearchPoint connects, parses, and retrieves company knowledge with fail-closed security at every hop.

01. Delta Ingest

Microsoft Graph delta queries and local filesystem watchers discover document updates without copying binaries.

02. Rust Sandbox

Dedicated high-performance Rust worker processes PDF, Office, and OCR in an ephemeral sandbox. Immediate memory purge.

03. Purview Snapshot

Every record carries its native Entra ID source allow-list (users, groups, public) — the sole signal for query authorization.

04. OpenSearch Engine

Sub-50ms vector and keyword retrieval with boolean operators, fuzzy matching, and multilingual English/Indonesian stemming.

05. Grounded RAG

Permitted context citations feed your favorite LLM (Claude, ChatGPT, Ollama) with zero hallucinations and zero data leakage.

Zero-Trust Framework

Your files stay where they are. Permissions intact.

SearchPoint never becomes an accidental oversharing engine. If a user cannot open the file in OneDrive, they cannot even see it in search.

Document Allow-List

Every indexed document carries its actual source permissions (users, groups, public) — the sole authorization signal for search visibility.

Fail-Closed Authorization

If a document's permission snapshot is missing, corrupt, or incomplete, access is denied. The search engine never defaults to 'visible'.

HashiCorp Vault Secrets

All credentials, tokens, and keys are stored and rotated in Vault with cloud-KMS auto-unseal (AWS/Azure/GCP) and transit secret workflows.

mTLS & Certificate Revocation

Client certificates are verified and revocation-checked at the Caddy proxy layer — stolen or expired certificates cannot be replayed.

Truth-Mirroring Deletes

When a file is deleted, moved, or locked down in OneDrive or SharePoint, it disappears from search instantly. No ghost copies.

Complete Audit Logging

All search queries and document open events are logged and aggregatable per user. Internal metrics listen on private network interfaces only.
